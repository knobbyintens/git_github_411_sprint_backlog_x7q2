# git_github_411_sprint_backlog_x7q2

Customer-success feature intake and sprint triage workspace.

## Layout

- `intake/feature_requests.json` - inbound feature requests for the current cycle
- `config/teams.json` - owning teams, their GitHub labels and component scope
- `docs/triage_policy.md` - acceptance, routing and duplicate-handling policy
- `triage/` - sprint triage log produced by the planning run

Issues in this repository track accepted work items for the sprint.
